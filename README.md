# IICT AI & Machine Learning Internship Projects

This repository contains the practical projects completed during my 45-day Summer Internship at the **Indian Institute of Computing and Technology (IICT)** (Affiliated with I-STEM, Office of the Principal Scientific Adviser to the Govt. of India).

---

## 📌 Projects Included

### 1. AI-Powered Fake News Detection Using Text Classification
* **Objective:** Classify news articles as real or fake based on language patterns and textual features.
* **Tech Stack:** Python, Pandas, Scikit-Learn, NLTK, Jupyter Notebook.
* **Key Steps:** Text cleaning, TF-IDF vectorization, model training, and performance evaluation.

### 2. AI-Driven Phishing Email Detection Using NLP
* **Objective:** Identify malicious phishing emails by extracting key textual indicators.
* **Tech Stack:** Python, Natural Language Processing (NLP), Scikit-Learn, Jupyter Notebook.
* **Key Steps:** Tokenization, feature extraction, text classification, and testing.

## Phishing Email Detection

An AI-powered phishing email detection system using NLP, TF-IDF, and a Neural Network.

Best model: Neural Network
Accuracy: 96.73%

Run the application:

pip install -r requirements.txt
streamlit run app.py
